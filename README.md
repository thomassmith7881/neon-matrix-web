Zero-dependency, 60fps responsive digital rain effect in pure HTML5 and vanilla JavaScript.

## Features
- ⚡ **Pure Vanilla JS**: No frameworks, no external libraries.
- 📱 **Fully Responsive**: Adapts automatically on browser resize.
- 🎨 **Minimal Footprint**: Single small HTML, CSS, and JS file.

## Preview
Open `index.html` in any modern web browser.
